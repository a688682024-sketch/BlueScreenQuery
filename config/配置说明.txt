蓝屏代码查询器 2.0 · 配置文件说明
================================================================

这个文件夹里的所有文件都是【可选】的。

    · 删掉任何文件 → 程序用内置默认值，功能完全正常
    · 改坏了 / 写成非法 JSON → 程序忽略该文件，仍用默认值启动
    · 不知道该写什么 → 不要动，保持现状即可

换句话说：这些是给愿意折腾的人准备的，不是运行必需品。


一、文件清单
----------------------------------------------------------------

  app.json          外观与窗口：主题、字号、窗口尺寸、免责声明文案
  search.json       搜索行为：防抖毫秒、结果上限、模糊匹配开关
  shortcuts.json    快捷键：可改键，也可留空禁用


二、优先级（重要）
----------------------------------------------------------------

  你在程序「设置」里改过的内容  >  这里的配置文件  >  程序内置默认值

也就是说：
  · 配置文件影响的是「首次运行」和「设置里没有对应项」时的默认值
  · 如果你已经用图形界面调过主题/字号，再改 app.json 不会覆盖你的选择
  · 想以配置文件为准，把用户数据目录里的 user.db 删掉即可（会丢收藏和历史）


三、app.json
----------------------------------------------------------------

  theme         "dark" 或 "light"，默认深色
  font_size     界面字号，8 ~ 16，默认 10
  window.width / height         首次打开的窗口尺寸
  window.min_width / min_height 窗口最小尺寸（不建议调太小，布局会挤）
  disclaimer    底部状态栏右侧那行免责声明文字


四、search.json
----------------------------------------------------------------

  debounce_ms     输入后等待多少毫秒再搜索，建议 150 ~ 400
                  调小：更灵敏，但计算更频繁
                  调大：更省资源，但打字时反馈延迟
  max_results     单次最多显示多少条结果
  fuzzy_fallback  结果很少时是否容忍拼写错误（true / false）


五、shortcuts.json
----------------------------------------------------------------

  写法是 Qt 的键序列，例如：
      Ctrl+K        Ctrl+Shift+F      Alt+1      F5

  可配置项：
      focus_search      聚焦搜索框
      copy              复制当前条目
      favorite          收藏 / 取消收藏
      settings          打开设置
      filter_all        筛选：全部
      filter_favorite   筛选：收藏
      filter_recent     筛选：最近
      escape            清空搜索 / 关闭详情

  留空（""）表示禁用这一条。
  如果某条写错，只有那一条失效，其余照常。


六、出问题怎么办
----------------------------------------------------------------

  程序启动后可正常使用 → 说明配置已被忽略，你的填写有语法错误
  JSON 常见错误：
      1. 少了逗号，或多了一个逗号
      2. 用了中文引号 “” 而不是英文引号 ""
      3. 数字加了引号（"300" 在某些位置会被当作字符串）

  最省事的验证方式：把改过的文件删掉，让程序回到默认值。
