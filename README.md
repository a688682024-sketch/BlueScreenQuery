# Windows 蓝屏代码查询

一款专为 Windows 用户设计的蓝屏代码查询工具，收录 105 种常见蓝屏错误代码，涵盖内存管理、驱动程序、文件系统、图形显示、硬件故障等多个类别。无需联网，本地数据，即开即用。

## 功能概述

- 覆盖 105 种常见蓝屏代码，支持完整代码、简写、名称、中文关键字等多种输入方式
- 模糊搜索，输入关键词即可快速定位相关代码
- 每条代码附带详细含义解释和具体解决方法
- 本地运行，无需联网，不收集任何用户信息

## 获取方式

### 方式一：直接使用（推荐普通用户）

前往 Releases 页面下载 BlueScreenQuery_Setup.exe 安装包，双击安装即可使用。

### 方式二：自行打包（适合有 Python 环境的开发者）

需要下载blue_screen_query.py+bluescreen_data.json+build_exe.bat，文件尽量下载到同一个文件夹内

为了减少错误出现率，建议先把bat的代码和文件名，包括文件后缀！！！复制下来，然后在下载好的文件夹目录下新建文本文档，先粘贴复制好的代码，然后[另存为],这时文件重命名再粘贴文件名，包括文件后缀！！！，编码选择AHSI，确定保存即可做成一键打包成打包，需要确定三个文件在同一个文件夹下，才可以双击运行bat,等待自动打包完成后在 dist 目录下找到 BlueScreenQuery.exe，双击即可运行。

## 使用方法

1. 打开程序，在搜索框中输入蓝屏代码或关键字
2. 支持输入格式：0x00000050、50、MEMORY_MANAGEMENT、内存
3. 点击查询或按回车查看结果
