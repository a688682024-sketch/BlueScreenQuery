# Windows 蓝屏代码查询

一款专为 Windows 用户设计的蓝屏代码查询工具，收录 105 种常见蓝屏错误代码，涵盖内存管理、驱动程序、文件系统、图形显示、硬件故障等多个类别。无需联网，本地数据，即开即用。

## 功能概述

- 收录 105 种常见 Windows 蓝屏代码，覆盖内存管理、驱动程序、文件系统、图形显示、硬件故障等主要类别
- 支持多种输入方式：完整代码（0x00000050）、简写（50）、错误名称（MEMORY_MANAGEMENT）、中文关键字（内存）
- 输入关键词即可模糊搜索，快速定位相关代码
- 每条代码附带含义解释和解决方法，方便对照排查
- 本地运行，无需联网，不收集任何用户信息
- 界面简洁，操作直观，打开即用

## 获取方式

### 方式一：直接使用（推荐普通用户）

前往 Releases 页面下载 BlueScreenQuery_Setup.exe 安装包，双击安装即可使用。

### 方式二：自行打包（适合有 Python 环境的开发者）
  
> 要求 Python 3.8 或更高版本（例如 3.8、3.9、3.10、3.11、3.12、3.13、3.14 等均可）。  
> 不知道当前版本的，可以在命令提示符（CMD）中输入 `python --version` 查看。  
> 简单来说，保证版本号中“3.”后面的那个数字大于或等于 8 就行。

 
  
需要下载 `blue_screen_query.py`、`bluescreen_data.json`、`build_exe.bat` 三个文件，文件尽量下载到同一个文件夹内。

为减少错误出现率，建议按以下步骤操作：

1. 先用记事本打开 `build_exe.bat`，把里面的代码全部复制下来
2. 同时把 `build_exe.bat` 这个文件名（包括后缀 .bat）也复制下来，后面要用
3. 在下载好的文件夹目录下，新建一个文本文档
4. 打开新建的文本文档，先粘贴刚才复制的代码
5. 点击菜单栏的 `文件` → `另存为`
6. 在弹出的窗口中，将文件名改为刚才复制的 `build_exe.bat`（注意后缀必须是 .bat）
7. 编码选择 `ANSI`，点击确定保存
8. 确保 `blue_screen_query.py`、`bluescreen_data.json` 和刚保存的 `build_exe.bat` 三个文件在同一个文件夹下
9. 双击运行 `build_exe.bat`，等待自动打包完成
10. 打包完成后，在生成的 `dist` 文件夹中找到 `BlueScreenQuery.exe`，双击即可运行


## 使用方法

1. 打开程序，在搜索框中输入蓝屏代码或关键字
2. 点击查询或按回车查看结果
